# 프로젝트와 팀 관리 구현

## 구현 범위

- 가입 완료 계정의 프로젝트 생성, 목록 검색과 커서 페이지, 상세 조회
- 현재 소유자의 기본 정보 수정, 이름 확인 후 삭제, 소유권 이전
- 팀원 목록, 자기 탈퇴, 소유자의 팀원 제거
- 활성 팀원의 초대 링크 발급과 회전, 익명 초대 확인과 명시적 수락
- 제거된 팀원의 기존 링크 재사용 차단과 새 링크를 통한 재참여
- 프로젝트 생성과 팀원 제거의 멱등 재시도
- 사용자 잠금과 프로젝트 잠금으로 계정 탈퇴, 소유권 이전과 팀 변경을 직렬화
- 삭제된 프로젝트와 비활성 계정의 기존 문서 접근 차단

초대 토큰 원문은 해시로 조회하고 복원할 값은 암호화해서 저장한다
초대 수락은 프로젝트 잠금을 얻은 뒤 초대 상태를 다시 잠가 회전된 링크를 거절한다

## 검증

Java 21에서 운영 코드와 테스트 코드의 직접 컴파일을 통과했다
로컬 실행 환경의 Java 포트 열기 제한으로 Gradle과 HTTP 서버 테스트는 실행하지 못했다
GitHub Actions의 MySQL 8.4 환경에서 빌드와 전체 테스트 결과를 확인한다

실제 HTTP 요청을 쓰는 통합 테스트는 다음을 확인한다

- 이메일 코드 로그인과 세션 교체, 가입 동의 없는 프로젝트 접근 거절
- 두 계정의 초대 수락과 제삼자의 프로젝트 접근 거절
- 일반 팀원의 관리 작업 거절, 소유자의 자기 탈퇴 거절
- 팀원 제거 후 기존 URL 접근과 새 로그인 초기 정보 조회 후 접근 거절
- 검색과 페이지, 오래된 버전 거절, 삭제 이름 확인과 기존 초대 무효화
- 제거 요청 재전송, 초대 회전, 소유권 이전과 이전 소유자의 나가기 재전송

테스트 메일 발송은 대역으로 처리하며 외부 메일함 수신 검증은 아니다
브라우저에서 실제 서버와 연결한 검증, 실제 소셜 제공자 계정 왕복 검증은 별도로 필요하다
